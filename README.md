# 🔬 Cancer Image Detection With PyTorch

A deep learning model using CNN to detect 
cancerous patterns in medical images.

## 🎯 Motivation
Millions in Bangladesh lack early cancer 
diagnosis. This model aims to bridge that 
gap using Machine Learning.

## 🛠️ Tech Stack
- PyTorch
- CNN Architecture
- Python
- Google Colab

## 📊 Results
- Training Accuracy: ~85%+
- Model: 3-layer CNN
